# 0 · Fixed similarity rules

This stage asked whether a fixed rule over measured gene–gene similarity can predict the response to an unmeasured
knockdown better than a STRING neighbour average, and which similarity source and which weighting do it. It covers
the E series (E000–E122) from lab sessions 1–5, 2026-09-28 to 2026-10-01. Every experiment uses one dataset: the
Marson CD4+ T-cell Perturb-seq screen in three conditions (Rest, Stim8hr, Stim48hr), split by knocked-down gene into
5 folds (dev = folds 0–3, lockbox = fold 4). The prior sources were DepMap CRISPR co-essentiality, Replogle K562
genome-wide Perturb-seq, STRING, and about 25 others that failed. Sessions 1–4 scored arms on a metric that session 5
found biased. Session 5 rescored the key arms on a fixed gene panel, so the numbers below say which metric they use.
E071a, the zero-fit weighted partner average, is the direct ancestor of PWPA.

## Terms used in this file

- **Δ**: a knockdown's response (pseudobulk change against non-targeting cells), per readout gene. z layer for Pearson,
  log2FC layer for MSE.
- **k**: the context mean of the training knockdowns' Δ. **b** is the baseline that predicts k for every knockdown.
- **Context (ctx)**: one condition × one dev fold (12 per run). Every metric is computed per condition, then averaged.
- **Pearson Δ − k**: Pearson correlation of (prediction − k) with (truth − k) over a set of genes. b scores 0.
- **N = 100 / N = 300 (old metric)**: the genes are each test knockdown's own top-N DE genes by truth |z|.
- **Panel 300 (new metric, session 5)**: the genes are one fixed panel per (condition, fold), the 300 genes with the
  largest mean |z| over that fold's training knockdowns. Panel 100 is the same with 100 genes.
- **MSE**: mean squared error in log2FC on the same genes, raw outputs. Lower is better.
- **Retrieval**: rank of a knockdown's own truth among all test truths by similarity to its prediction (b and any
  shared prediction score 0.5). A diagnostic of gene specificity.
- **r (roof)**: the score of one donor half predicting the other. Pearson r ≈ 0.45 (old N = 300), ≈ 0.40 (panel).
- **Bar**: the lab's rule that an arm must beat its comparator by +0.03 Pearson Δ − k to count as an effect.
- **Headroom**: (b − x) / (b − r), the share of the b-to-roof gap an arm closes.
- **STRING top-20 (E000)**: the 20 highest-scoring STRING v12 partners of a target, unweighted, averaged over the
  partners that are training knockdowns. The session-5 rescoring notes this equals the "Fawkes" knowledge-graph
  neighbour-average baseline.
- **co-ess**: DepMap 24Q4 Chronos gene-effect profiles over 1,178 cancer lines, top 5 PCs removed, top-60% SD genes;
  similarity = Pearson r between two genes' profiles. **K562**: Replogle 2022 genome-wide K562 Perturb-seq profiles of
  genes passing the energy test (p < 1e-3); similarity = Pearson r between knockdown profiles.
- **r³ / sharpening**: raising the similarity to the third power before using it as a weight.
- **Kernel ridge (E043 onward)**: P = k + K_test,train (K_train,train + λI)⁻¹ Y over all training knockdowns, with K a
  sharpened similarity. **Smoother**: the same with λ → ∞, a similarity-weighted average.
- **g (generic direction)**: mean Δ − k of the context's 20 strongest training knockdowns.
- **Own-profile step**: averaging the kernel direction with a map of the target's own K562 (or DepMap) profile.
- **rw0, rw1, rw2 (rewired)**: the graph's edges or gene labels shuffled with seed 0, 1, 2. **perm0**: the same idea
  for model arms (a source's gene-to-row map permuted, seed 0). Both are negative controls.
- **E008 labels**: an LLM's assignment of 11,492 screen genes to 41 programmes (TCR signalling, IL-2/STAT5, OXPHOS, …).
- **ORCS**: the BioGRID ORCS CRISPR-screen database. **NNLS**: non-negative least squares. **β**: a fitted
  non-negative component weight.

## Metric warning

- **Sessions 1–2** scored Pearson Δ − k and retrieval on each test knockdown's own top-100 DE genes (N = 100).
  **Session 3** made N = 300 primary and kept N = 100. **Session 4** replaced retrieval with MSE in log2FC on the
  same top-300 genes as the second axis.
- **This selection is biased.** Picking genes by the truth's own |z| makes the truth overshoot k there (winner's curse),
  so any prediction pushed along k gets free credit: "k × 1.1 for every knockdown" scored 0.286 on the old dev N = 300
  metric, above STRING (0.215), and −0.024 on panel 300 (Δ vs STRING −0.207 ± 0.009). Sizes and blend weights fitted
  on truth-picked genes (E110e–E119) also overshoot on MSE.
- **From session 5** (2026-10-01) the metric is panel 300: Pearson Δ − k (b = 0, STRING 0.183, r 0.397, dev) and MSE
  in log2FC (b 0.117 dev, STRING 0.144). b is the bar on MSE.
- All numbers in this file are dev unless marked lockbox. Old-metric and panel numbers are not on one scale. Only the
  arms in the rescoring table below were rescored; every other number is old-metric, and its Δ vs STRING should be
  read as an upper bound.

## What this stage established

1. **Measured phenocopy beats STRING; the effect survived the metric fix at about half its size.** Old metric: DepMap
   co-ess top-20 (E016a) +0.064 ± 0.007 vs STRING (dev, N = 100); co-ess + K562 + STRING (E016c) +0.073 ± 0.006 (dev),
   +0.084 ± 0.014 (lockbox, N = 100); one-rule GRN E071a +0.091 ± 0.007 (N = 300). Panel: E071a +0.050 ± 0.007 (dev),
   +0.068 ± 0.015 (lockbox). Matched random partners from the same pools fall to the floor (E005c, E016d), so the gain
   is the specific partners. (E005, E016a–d, E071a; #6, #9, #13, #68, #129.)
2. **DepMap co-essentiality is the core source; K562 Perturb-seq is second and helps only where both exist.** Co-ess
   alone beat K562-based E005e by +0.030 ± 0.007 (old N = 100). In the two-kernel ridge, K562 added +0.039 ± 0.007 on
   the 1,250 rows with both profiles and +0.001 on co-ess-only rows (E045). Removing K562 from the session-3 front cost
   −0.021 ± 0.004 (E099a). Co-ess needs many diverse lines: 135 blood lines only lost −0.077 ± 0.007 (E016e); RNAi
   co-dependency −0.124 ± 0.008 (E046); HAP1 genetic interactions −0.051 ± 0.007 vs STRING (E039). Old metric
   throughout; the panel-era F016 ablation agrees that DepMap is the core (#136). (#13, #17, #35, #40, #42, #98.)
3. **How much each partner counts matters as much as which partners: r³ weights.** Same top-20 edges with weight
   sign(s) instead of s: −0.044 ± 0.003 (E071b vs E071a). No sharpening in the kernel smoother: −0.042 ± 0.004 (E066e).
   The ridge solve is worth 0.010, cross-validated knobs 0 (E066, E070: every |Δ| ≤ 0.0004 vs the CV arms). STRING
   given the same sharpened map gains only +0.029 ± 0.004 (E086b), so most of the gap is the relation, not the map.
   A published DepMap-PCA ridge ties STRING (+0.006 ± 0.009, E081a). Old N = 300. (#67, #68, #69, #83, #84, #86.)
4. **Interaction, literature, embedding, LLM and other measured sources do not beat STRING or add to the kernels.**
   Old-metric Δ vs STRING: single STRING channels −0.012 to −0.119 (E011); GenePT −0.084 ± 0.008 (E024a); PubTator3
   −0.147 ± 0.008 (E054); HumanBase T-cell network −0.126 ± 0.009 (E058); Affinage literature −0.023 ± 0.005 (E033);
   complexes −0.003 to −0.004 (E038); protein co-abundance −0.047 ± 0.008 (E042); morphology −0.028 ± 0.004 (E040b);
   L1000 −0.078 (E069b); LLM phenocopy partners +0.014 ± 0.005 dev and −0.008 ± 0.012 lockbox (E034). On top of the
   two kernels: STRING −0.000 ± 0.001 (E047), LLM partners −0.002 ± 0.002 (E047b), HCT116 Perturb-seq +0.0006 ± 0.0007
   (E050), other-line Perturb-seq +0.002 ± 0.002 (E048), ORCS hit calls +0.003 ± 0.003 (E073a), signalling atlas
   +0.0005 ± 0.0003 (E076a). (#5, #24, #32–#36, #39, #43, #44, #48, #51, #56, #71, #75, #76.)
5. **The screen's own training responses do not pick better partners.** Readout co-response −0.141 ± 0.009 (E002);
   "j moves i" −0.221 ± 0.011 (E003); a learned edge score −0.056 (E013); re-picking partners by response coherence
   −0.048 ± 0.005 vs E016c (E019). Old N = 100. (#1, #2, #11, #21.)
6. **STRING is not needed once measured kernels exist.** Replacing the STRING fallback on no-profile rows with k +
   unit(g) gained +0.006 ± 0.002 (E092a vs E070b, old N = 300). Every form of STRING scores ≈ 0.066 on the 402
   no-profile dev rows (#85). (#43, #88.)
7. **Own-profile steps and the generic direction built the old front, but only on the old metric.** E098a (kernel +
   own-K562 step + own-DepMap step + DepMap-ridge fill + 0.5·unit(g)) reached 0.364 (+0.149 ± 0.008, old N = 300).
   Its sized version E110e rescored at +0.041 ± 0.009 on the panel, below E071a's +0.050. These pieces cost at 10% of
   the data (E106: g −0.012, DepMap fill −0.007, own-DepMap step −0.008), so E070a is the low-data rule. (#90, #96,
   #103, #129.)
8. **Every MSE gain of session 4 was the truth-picked fit; fitting on a training panel is the lever.** Old: E110e
   −0.082 ± 0.005, E114 −0.117 ± 0.005, E119 −0.127 ± 0.005 vs STRING MSE. Panel: E110e 0.180 and E119 0.230 against
   b 0.117 and STRING 0.144. With β or a shrink fit on the training panel: E121 0.108, E122 0.108, E120 0.112, all under
   b. E120's shrink c is 0.27–0.52, so the zero-fit partner average moves 2–3× too far. (#111, #123, #127, #129, #130.)
9. **Primary T-cell CRISPR screens carry the TCR phenocopy that DepMap lacks, but help only on T-cell genes.** On the 55
   TCR + IL-2/STAT5 targets the 37-screen kernel alone scores 0.457 vs STRING 0.330 (E109d, old N = 300). Every gate
   that also touched other genes lost overall: −0.047 ± 0.004 (E109b), −0.050 ± 0.004 (E109c), −0.031 ± 0.003 (E109e),
   −0.026 ± 0.004 (E109f), −0.008 ± 0.003 (E109g). Gating by the a-priori LLM programme label was the first that did
   not lose: +0.006 ± 0.002 overall, +0.258 ± 0.060 on TCR + IL-2/STAT5 vs E110e (E109h). As an NNLS component it adds
   +0.0068 ± 0.0012 (E116). Old metric only; the panel refits E121 / E122 include the component but no panel ablation
   of it exists in this stage. (#109, #110, #112–#114, #119, #120, #125.)
10. **The prior is worth several times the data, and co-ess generalises beyond T cells (old metric).** E070a on 10% of
   training knockdowns (0.201) ties STRING on all of them (0.205–0.215) (E091). A kernel-designed 10% beats a random 10%
   by +0.051 ± 0.006, and by +0.038 ± 0.006 when the design never sees test genes (E096, E100). In kernel form co-ess
   beats STRING in K562 genome-wide (+0.050 ± 0.006, E052) and RPE1 (+0.035 ± 0.007, E059) and ties it on core-essential
   genes. These used truth-picked gene sets and were not rescored. (#47, #55, #90, #94, #97.)

## Experiments

Numbers are dev (folds 0–3) unless marked lockbox. "Old" means the truth-picked metric of sessions 1–4 (N = 100 or
N = 300 as stated); "panel" means the fixed 300-gene training panel of session 5. Δ is paired against the named
comparator, mean of the three condition means ± SE.

### E000 · STRING top-20 baseline
- **Question:** the reference prior: how well does averaging a target's STRING partners predict its response?
- **Setup:** Marson, dev and lockbox. Per target, the 20 highest-scoring STRING v12 partners (combined score), weight 1,
  averaged over those that are training knockdowns of the condition; targets with no such partner get k. Nothing fitted.
  Control: rewired graph (rw0).
- **Prediction:** none (baseline).
- **Result:** old dev N = 100: Pearson Δ − k 0.224 (Rest 0.162, Stim8hr 0.240, Stim48hr 0.270), retrieval 0.673; N = 300:
  0.215, MSE 0.659 (b 0.685). Old lockbox N = 300 0.229, MSE 0.647. Rewired: N = 300 −0.010 (−0.225 ± 0.009 vs E000).
  Panel dev 0.183, MSE 0.144 (b 0.117), retrieval 0.650; panel lockbox 0.200, MSE 0.130. Panel rewired −0.004
  (−0.187 ± 0.009).
- **Verdict:** baseline. The comparator for every arm in sessions 1–5.
- **For later work:** STRING's raw outputs are over-confident on MSE (one shared prediction, E010, beat it on old MSE:
  0.637 vs 0.659, #107; on the panel STRING 0.144 is above b 0.117). STRING covers only 86–92% of dev targets with a
  training partner.
- **Source:** `lab/exp/E000-string/` (archived: no; no README, arm.py and metrics only), findings "Setup facts", #64, #129.

### E002 · Readout co-response graph (with E003)
- **Question:** can a graph built from the screen's own training knockdowns beat STRING? E002 links gene i to training
  knockdowns whose readout columns co-vary with i's column; E003 links i to the knockdowns that move i most.
- **Setup:** Marson, dev, old N = 100. Top-20 by |r| (E002) or by −X[j,i] / |X[j,i]| (E003, E003b). Nothing fitted.
- **Prediction:** E002 ≥ STRING + 0.03.
- **Result:** E002 0.084, Δ −0.141 ± 0.009, retrieval 0.566 (−0.107 ± 0.008), coverage 90%; on covered genes still
  0.092 vs 0.223. E003 signed 0.003 (−0.221 ± 0.011); E003b unsigned 0.084 (−0.141 ± 0.010).
- **Verdict:** failed. Both sit below the one-prediction floor (E010, 0.157).
- **For later work:** "co-regulated as a readout" and "j moves i" are not "same knockdown response". With E013 and E019,
  every attempt to choose partners from the screen's own training responses lost to external measurements (#21).
- **Source:** `lab/exp/E002-readout-corr/`, `E003-regulator-edges/`, `E003b-regulator-edges-abs/` (archived: yes),
  findings #1, #2.

### E005 · K562 knockdown phenocopy as neighbours
- **Question:** does phenocopy measured in another cell type (Replogle 2022 genome-wide K562 Perturb-seq) transfer to
  T cells better than STRING's "these interact"? Parent: E001a, which found good STRING edges follow response
  similarity (Spearman 0.46–0.55), not STRING score (0.05–0.12).
- **Setup:** Marson, dev, old N = 100. 3,081 K562 targets pass the energy test p < 1e-3 (2,160 in the 11,526-gene
  universe). Pearson r over the 3,000 most variable readouts; top-20 training knockdowns by |r|, weight r. Covers
  46 / 50 / 54% of test targets. Control: rewired.
- **Prediction:** alone below STRING (u ≈ 0.15–0.20); a STRING-fallback hybrid (E005b) might reach +0.03.
- **Result:** alone 0.185, Δ −0.039 ± 0.008; on covered genes 0.349 / 0.359 / 0.405 vs STRING 0.265 / 0.331 / 0.370,
  mean +0.049 ± 0.011. Rewired 0.035 / 0.502. E005b (STRING fallback) +0.024 ± 0.005. Matched random partners from the
  K562-strong pool (E005c): 0.101 vs 0.371 on covered genes.
- **Verdict:** superseded by E005e; the first lead.
- **For later work:** measured knockdown similarity works where it exists; coverage limits it. Keep the strict energy
  filter (looser p < 0.05 adds noise genes, E005d).
- **Source:** `lab/exp/E005-k562-phenocopy/` (archived: no), findings #6, #9.

### E005e · STRING top-10 + K562 top-10
- **Question:** are K562 phenocopy and STRING complementary on the genes both cover? Parent: E005b.
- **Setup:** Marson, dev, old N = 100. K562-covered targets: STRING top-10 (weight 1) ∪ K562 top-10 training knockdowns
  (weight sign(r)); others STRING top-20. Nothing fitted. Controls: rewired seeds 0–2.
- **Prediction:** ≥ STRING + 0.03, retrieval > E005b, covered-gene Pearson above E005.
- **Result:** 0.258, Δ +0.033 ± 0.005 (Rest +0.037, Stim8hr +0.026, Stim48hr +0.037); retrieval 0.690 (+0.017 ± 0.004).
  Covered genes 0.389 vs STRING 0.322 (+0.067 ± 0.009) and vs E005 +0.018 ± 0.004. Rewired −0.002 / −0.000 / −0.002.
- **Verdict:** superseded by E016c. First prior over the bar, marginally (Stim8hr alone misses it).
- **For later work:** a light K562 share is better than a heavy one (STRING15 ∪ K562-5 +0.009 ± 0.002 over 10/10,
  E005g); the opposite holds for co-ess, where STRING dilutes (#15).
- **Source:** `lab/exp/E005e-k562-string-mix/` (archived: no), findings #10, #15.

### E010 · One shared prediction (hub control)
- **Question:** how much of a prior's Pearson Δ − k is generic strong-knockdown signal rather than gene-specific?
- **Setup:** Marson, dev, old N = 100. Every test gene's neighbours = the 20 strongest training knockdowns by ‖Δ − k‖,
  weight 1, so every test gene gets the same prediction.
- **Prediction:** Pearson Δ − k ≈ 0.05–0.10.
- **Result:** 0.157 (Rest 0.151, Stim8hr 0.112, Stim48hr 0.207), Δ −0.068 ± 0.010 vs STRING; Rest −0.012 ± 0.016.
  Retrieval exactly 0.500. Old N = 300 0.151, MSE 0.637 (STRING 0.659).
- **Verdict:** control. Larger than predicted: 70% of STRING's score (93% in Rest) with no gene-specific information.
- **For later work:** a Pearson gain without a retrieval gain may be generic. The generic direction g built from this
  idea was added to the front in E012 / E017 / E070b and fitted as a component in E114.
- **Source:** `lab/exp/E010-hub-control/` (archived: yes), findings #3, #107.

### E016a · DepMap co-essentiality top-20
- **Question:** is fitness co-essentiality across ~1,100 cancer lines a genome-wide phenocopy proxy? Parent: E016
  (the build).
- **Setup:** Marson, dev, old N = 100. DepMap 24Q4 Chronos, 1,178 lines × 17,916 genes; gene-centred, top 5 PCs removed;
  top-60% SD floor (10,295 genes, 7,129 in the universe). Top-20 training partners by |r|, weight r; STRING top-20
  for uncovered targets. Covers 78.5 / 82.6 / 85.4% of test targets. Nothing fitted. Controls: rewired seeds 0–2.
- **Prediction:** ≥ STRING + 0.01.
- **Result:** 0.288, Δ +0.064 ± 0.007 (Rest +0.069 ± 0.013, Stim8hr +0.048 ± 0.010, Stim48hr +0.074 ± 0.012); retrieval
  0.712 (+0.039 ± 0.006). vs E005e +0.030 ± 0.007. Covered genes 0.338 vs 0.261 (+0.077 ± 0.008). Rewired 0.005 / −0.006 /
  −0.005. Old N = 300: 0.274 (+0.059 ± 0.007). Not rescored on the panel.
- **Verdict:** superseded by E016c, then E043 / E071a. The strongest single source.
- **For later work:** co-ess wants many diverse lines (blood lines only −0.077 ± 0.007, E016e); the SD floor (40–60%)
  and PC count (0 / 5 / 20) barely matter (E016f, E026). Adding STRING dilutes it (E016b −0.013 ± 0.003). It loses on
  TCR signalling genes (−0.084 ± 0.058, n 44, E018) because those genes are not variable in cancer lines.
- **Source:** `lab/exp/E016a-coess-fallback/`, `E016-depmap-coessential/` (archived: no), findings #13, #17, #19, #25.

### E016c · STRING-10 ∪ K562-5 ∪ co-ess-5
- **Question:** does co-essentiality add to the best prior E005e?
- **Setup:** Marson, dev and lockbox, old N = 100. K562 ∩ co-ess targets (1,249 rows): STRING top-10 ∪ K562 top-5 ∪
  co-ess top-5; co-ess only (934): STRING top-10 ∪ co-ess top-10; K562 only (72): E005e's mix; neither (402): STRING
  top-20. Nothing fitted. Controls: rewired seeds 0–2.
- **Prediction:** ≥ E005e and ≥ STRING + 0.03.
- **Result:** 0.298, Δ +0.073 ± 0.006 (Rest +0.071, Stim8hr +0.061, Stim48hr +0.088); retrieval 0.721 (+0.048 ± 0.005);
  vs E005e +0.040 ± 0.005; vs E016a +0.010 ± 0.005. Rewired −0.003 / −0.016 / −0.009. Lockbox (scored once, session 2):
  0.324, +0.084 ± 0.014 vs STRING, inside its pre-registered band (+0.055 to +0.091). Old N = 300 0.283 (+0.068 ± 0.006).
  Not rescored on the panel.
- **Verdict:** superseded by E071a (one score, no slot rules: +0.023 ± 0.004 over E016c at N = 300).
- **For later work:** hard per-source slot rules are worse than one joint weighted score.
- **Source:** `lab/exp/E016c-string10-k562-coess/` (archived: no), findings #13, #64, E062 README.

### E016d · Matched random co-ess partners (control)
- **Question:** is E016a's gain the specific partners, or just drawing from the co-ess-covered pool?
- **Setup:** as E016a, but 20 random partners from the same co-ess-covered pool.
- **Prediction:** at the floor.
